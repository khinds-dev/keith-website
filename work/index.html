Personal blog platform

Part of this site

A custom blog API built with Node.js and Express, backed by SQLite. Handles post creation, editing, image uploads, and serving posts with server-side computed excerpt and reading time fields. An admin interface lets me write and publish without touching the database directly. The front-end Markdown renderer is hand-rolled: no libraries, handles fenced code blocks, ordered and unordered lists, headings with IDs, and inline formatting.

The interesting design constraint was keeping the whole thing deployable as a single docker compose up with no external services, no managed database, and no secrets beyond the Cloudflare tunnel token.

CICS test automation work

IBM internal

At IBM I've built and maintained automated test frameworks for CICS Transaction Server: system-level tests that exercise the full product stack including 3270 terminal interactions, JVM servers, Liberty runtime integration, and transaction management behaviour. The framework runs thousands of test scenarios across multiple CICS configurations and release streams, with test output designed for fast failure triage.

The interesting engineering problems: making test environments reliably reproducible, keeping the test suite fast enough to run in CI without sacrificing coverage, and designing failure output that tells you exactly what went wrong without requiring you to rerun the test in a debugger. Most of the real work is in the infrastructure around the tests, not the tests themselves.
