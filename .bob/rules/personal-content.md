# Rule: Personal Content — Only Assert What the User Has Stated

## Core rule

Never invent, assume, or infer personal facts about Keith. Only write personal content that the user has explicitly stated in the current conversation, or that is already confirmed in `AGENTS.md`.

**Personal facts** include but are not limited to:
- Hobbies and interests
- Possessions (pets, vehicles, equipment)
- Daily routines and habits
- Relationships and family
- Physical activity (gym, sport, walking)
- Food, drink, or lifestyle preferences
- Places lived or visited
- Opinions on specific things

## Why this matters

This is a personal website. Every paragraph in the About, Interests, and Now pages makes first-person claims on Keith's behalf. Plausible-sounding content that turns out to be fabricated has to be hunted down across multiple pages and corrected. It also erodes trust in anything else on the site.

## What to do if unsure

If writing personal content and a fact is unclear or not yet established, ask rather than guess. A short question is far less work than a multi-file correction pass.

## Examples

| Wrong | Right |
|---|---|
| "I also have a dog..." | Ask whether Keith has a dog before writing this |
| "I read a lot of history..." | Only write this if Keith has said he reads history |
| "I enjoy running..." | Only write this if Keith has mentioned running |
